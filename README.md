A newspaper front page summing up the world's news of Thursday 19 November 2026: the first US–China–Russia summit in Shenzhen, the World Court's Myanmar ruling, the COP31 draft deal, and the day's other major stories from every continent — politics, courts, climate, markets, sport and culture, with a world map showing where each story happened.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` into the output directory.
